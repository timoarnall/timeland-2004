# _speculation_other_datasets
Exploratory work testing whether the Timeland rendering approach (a GPS track with time-tagged events blooming along it) could work with datasets other than the original 2004 photos.

**Contains**: build scripts and logs for several candidate trips (bkk-burma-2012, summer-2010, norway-weekend-2013), each with JSON data files and segmented output folders (`__seg1` to `__seg6`), density analysis text files, a render preview (`render.html`), a screenshots folder of test seeks, and notes in `CANDIDATES.md`, `FINDINGS.md` and `HANDOVER.md`.
