# experiment-2026
A 2026 web build of the Timeland piece, running the original concept with real image and GPS data.

**Contains**: `index.html` (the running page), `build_imagedata.py` (generates image data from photos), and a `data` folder with a GPX track (`timo_iceland_noflight.gpx`), `imageData.xml`, and photo folders (`photos`, `photos_320`).
